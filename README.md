# Shorty

A tiny URL shortener built with Express, Pug, SQLite, and [Oat UI](https://oat.ink).

Shorten a URL, watch its click count go up, and delete links you no longer need.

> **Note:** This project was vibecoded with the help of AI.

## Requirements

- Node.js 24 or newer (uses the built-in `node:sqlite` module)
- pnpm

## Getting started

```bash
pnpm install
pnpm start
```

Open <http://localhost:3000>.

For development with automatic restarts:

```bash
pnpm dev
```
